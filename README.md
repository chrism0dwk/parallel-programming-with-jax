Introduction to Parallel Computing with JAX
===========================================

This simple notebook provides some exercises to accompany a slide deck on 
parallel computing.

To run the notebook, first install the [`uv`](https://docs.astral.sh/uv/) package dependency manager.   Then, clone the repository and run the notebook using `uv`:

```bash
git clone https://gitlab.com/chrism0dwk/introduction-to-parallel-computing.git
uv run jupyter-lab
```

Alternatively, open the notebook in [Google Colab](https://colab.research.google.com).
